PRIVACY APPROACH

Clear about what exists today.

NextGen PDF V1 sends files to the processing API to perform the selected operation. The current MVP does not intentionally persist uploaded or generated files after the request is completed. Review and update this page before public launch to match your final hosting, logging and retention configuration.

Current frontend

Files are processed by the NextGen PDF backend. The MVP streams the result back to the browser and does not intentionally save uploaded files to a permanent application database or file store.
